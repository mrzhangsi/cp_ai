# CP-AI
- 为内部用户提供各种开箱即用的AI能力，网页端形式
- 先实现Agent对话，知识库管理功能，Agent可智能调用知识库
## 技术栈
前端：Vue3
后端：fastapi，langchain
数据库：PostgreSQL
## 后端架构
先按功能进行模块化开发，具体的架构分层再说
## 开发
### 对话功能
- 用户输入，模型回复
- 附带历史记录
### 对话模型模块
- 使用langchain库，封装模型调用，对外提供统一的调用接口
- 不提供用户自定义功能，内部开发者通过.env文件配置模型参数，用户只能选择内置模型
### 记忆管理模块
- 对于一条记忆，不管是从哪来的，统一放到记忆管理模块处理
- 管理原始记忆，压缩后的记忆，用户记忆
- 用postgresql数据库存储，按用户id与会话id区分
- 记忆类型：用户输入，模型回复（直接存完整json），工具调用结果，摘要，
### 数据库模块
- 封装数据库操作，提供统一的数据库接口
- 把经过记忆模块处理后的记忆存入数据库
### Agent模块
- 封装对话功能，提供统一的对话接口
- 可以从记忆管理模块获取记忆，然后组装上下文，调用对话模型模块进行对话
